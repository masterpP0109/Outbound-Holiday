## 3. Why WordPress Previously Showed 0 Package & Guide Records
1. Built-in theme fallback (`inc/default-snapshot.json`) kept the public React site working even when `wp_posts` CPT tables (`package`, `guide_article`) were unseeded. Until **One-Click Import Built-in Theme Content into WordPress** was executed, `wp_count_posts('package')` and `wp_count_posts('guide_article')` returned `0`.
2. In addition, the earlier `inc/migration.php` importer omitted rich structured fields (`_outbound_badge`, `_outbound_categories_json`, `_outbound_detailed_itinerary_json`, `_outbound_highlights_meta_json`, `_outbound_recommended_hotels_json`, `_outbound_who_is_for_json`, `_outbound_author_json`, `_outbound_quick_facts_json`, `_outbound_reading_time`, `_outbound_published_date`, `_outbound_updated_date`, `_outbound_related_guides_json`, `_outbound_steps_json`, `_outbound_good_to_know_json`, `_outbound_why_recommend`, `_outbound_location_info_json`, `_outbound_at_a_glance_json`, `_outbound_facilities_json`) and depended on `clientGalleries` without falling back to bundled `albums`.
3. **Fix Applied**: Added clean per-record pure mappers (`outbound_map_accommodation_migration_record`, `outbound_map_experience_migration_record`, `outbound_map_package_migration_record`, `outbound_map_guide_migration_record`, `outbound_map_album_migration_record`), added fallback from `default-snapshot.json` for missing keys, added safe admin auto-seeding (`outbound_maybe_auto_seed_initial_content`) on first admin visit when CPTs are empty, and regenerated `docs/wp-conversion/outbound-migration-bundle.json`.

## 4. Performance & 502 Prevention Safeguards
- **On-Demand Single Record Loading**: CPT sections (`3`–`7`) query only **15 lightweight summary rows per page** (`wp_count_posts` + paginated `WP_Query`). Full visual repeaters (rooms, multi-day itineraries, guide chapters/blocks) ONLY load when editing ONE selected record (`?page=outbound-cms&section=...&edit_item=<ID>`).
- **Lightweight Related Content Lookup**: `outbound_editor_get_cpt_title_map()` runs a single static-cached `SELECT post_name, post_title` query per CPT instead of loading full postmeta objects for dropdown/checkbox selectors.
- **Transient Public Snapshot Caching**: Public API requests (`/wp-json/outbound/v1/snapshot`) serve from the `outbound_live_snapshot_v1` transient cache and request-level static cache, automatically invalidated via `outbound_invalidate_snapshot_cache()` on CMS Publish or `save_post`.
- **Non-Blocking Migration**: Image remote sideloading (`media_sideload_image`) is opt-in rather than forced across 50+ remote URLs in a single HTTP request, eliminating upstream PHP/FastCGI 502 gateway timeouts.
